Inertia's logos — one orbit, drawn several ways — as SVG with fixed colours (an `<img>` can't inherit `currentColor`). Use `-on-dark` files on Night grounds (`void`, `surface`; ink #f2ead9) and `-on-light` files on Day grounds (ink #1c1712). Hues: signal #f0643a / #e0532a, ion #3fc1b0 / #2a9d8f, pollen #e8ad35 / #e0a42a, walnut #8a6446 / #6b4a32, tide #7fa6d6 / #5b84bd, moss #a8b545 / #8a9a2b.

- `inertia-lockup-*` — mark + wordmark; default for headers and sign-in.
- `inertia-wordmark-*` — lowercase Schibsted Grotesk 600, outlined; ion and signal i-dots.
- `inertia-mark-*` — the orbit: signal body, ink ring, ion satellite. App icon and favicon.
- `inertia-realm-people-*` — the orbit as a horizon: signal body on a walnut Prairie double rule, pollen lamp.
- `inertia-realm-agent-*` — the orbit as a blueprint: ion linework, outlined body, solid satellite.
- `inertia-realm-org-*` — the orbit as a planet: tide body, moss ring, pollen moon.
