## Quality rubric

For each requirement, a reviewer scores usefulness: 0 missing/ceremonial, 1 useful partial, 2 substantive draft within available evidence. Report both the field-level scores and eligible-field denominator. Do not award points for filling genuinely unknown financial/legal/commitment fields with guesses. A proposed plan can score 2 as a proposal, never as historical fact.

### Reproducible scoring protocol

Before running a candidate, freeze each requirement's ID/version, route/owner, required answer components, source-span evidence, prohibited claims and expected genuine gaps. An independent reviewer admits this gold fixture, including answerable/not-answerable/partially-answerable classification with reasons. Calculate the denominator from the full sponsor requirement inventory. Omitted answers and unsupported-field hiding score zero; show lead-owned and genuinely unknown fields separately without deleting them from coverage.

1. **Hard checks:** deterministic validators check required fields, route/deadline disposition, evidence membership/version/hash, exact claim spans, numeric formulas/units, forbidden mutations, scope and historical cutoff. Store check ID, expected value, actual value and failure. Any material hard failure blocks qualification regardless of average score.
2. **Semantic rubric:** independent reviewers see the frozen requirement, exact answer and cited passages. Score 0 if absent, merely procedural/hedged, or materially unsupported; 1 if at least one required substantive component is supported but another answerable component is missing; 2 if all answerable components are substantively drafted, with only gold genuine gaps remaining. For each factual claim record supported/partial/unsupported/contradicted and supporting excerpt; proposed outcomes must be future-tense and cannot imply authorized resources.
3. **Prepared handoff (v3):** assess each request against its source-bound action plan and prepared work. Record preparation sufficiency, evidence supporting the action, decision precision and remaining agent work independently. Complete useful agent research before handing off a private-record or authority dependency. Rejected preparation must name the next agent step. Record the exact request, judgments and reasons.
4. **Adjudication:** two reviewers independently score all five cases using a versioned rubric. Store identities/model versions, inputs, scores and rationales; disagreements go to a separate adjudicator, with original votes retained. A designated human audits unresolved disagreements and every material unsupported claim before accepting a release comparison. A model's self-assessment is never the final acceptance record.

Persist per-case JSON with fixture/rubric/candidate/evidence hashes, deterministic results, independent assessments and adjudication. Re-running the arithmetic over these frozen records must reproduce reported metrics. Report model disagreements and preserve adjudication evidence. An unadjudicated case remains provisional.

Track supported factual claims / all factual claims; material unsupported claims; current requirement coverage; avoidable human requests; unresolved genuine decisions; route errors; human correction time; elapsed time; runtime/model/tool versions; token/tool cost when observable. A second reviewer independently checks all five cases and resolves scoring disagreements before comparison.

Initial qualification target (engineering choice): every demonstrably answerable field has a useful draft; every material factual assertion has claim-specific support; zero invented achievements, commitments or eligibility; zero avoidable human requests where existing current evidence directly answers the question. Report partial compliance and retain every safety failure as a blocking result. Quantitative comparison requires paired inputs and outputs.
