# Inertia critical path

Open [live chart](index.html). Every row links its closure plan. **⚠ means a clean plan has not yet been established**; it is separate from implementation status. Green means the specifically named capability has real evidence, not whole-system readiness.

Canonical state: [status.json](status.json). Earned-time proofs: [ledger](earned-time.md). Refresh the HTML after changes with `python3 scripts/render-chart.py` from this directory.

Root owns status/credit accuracy. Per-item owners maintain plans before unresolved development. Documentation is synchronized in the background; final demo review is last.
